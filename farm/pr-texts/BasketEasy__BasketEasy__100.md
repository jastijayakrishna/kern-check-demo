# Fix scoresheet uploads stuck at UPLOADED

## Summary
- `QueueModule`'s Redis connection used ioredis's default (infinite) reconnect strategy, so a misconfigured/unreachable `REDIS_URL` made every queue command (enqueue, worker polling) hang forever with no error or log line — uploads looked permanently stuck at `UPLOADED` with nothing to diagnose. Now caps reconnect attempts and logs connect/error/end events so a bad connection fails loud within ~15s.
- `gemini-client.ts` was pointed at `gemini-2.0-flash`, which Google has retired — every OCR job was failing after exhausting BullMQ's retries. Switched to `gemini-2.5-flash`, the current equivalent free-tier vision model.
