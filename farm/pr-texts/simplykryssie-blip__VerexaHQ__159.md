# Hide Learning Hub for unconnected Independent PTIN workspaces

## Summary

Learning Hub was always in the main nav regardless of workspace tier. For a solo Independent PTIN with no staff to train and no ERO connection, that's an always-empty page cluttering the nav for no reason — confirmed against a real (non-demo) workspace, "Terrelle Bethel," which has zero `firm_connections` rows today and would land on an empty catalog every time.

- Added `showLearningHub` computed server-side in `app/(app)/layout.tsx` (same pattern as the existing `showMessages`/`showEroManagement` props) and threaded it into `Sidebar.tsx`'s nav-item filter.
- **Hidden** for Independent PTIN tier only when it has zero active `firm_connections` rows as a child.
- **Still shown** for an Independent PTIN with an active connection to an ERO/Service Bureau, since `has_learning_hub_access()` already lets a connected PTIN view that ERO's shared published courses — a real, working feature (verified live against Summit Tax & Financial Services, which has an active connection to Demo - ERO Office).
- Always shown for ERO/Service Bureau/multi-office tiers, which author their own training for their own staff.
