# feat(web): microCMS 接続先の移行スクリプトと手順を追加

## Summary

旧 microCMS サービスから新サービスへコンテンツを移行し、アプリの接続先を切り替えるためのスクリプトと手順を追加します。

- `apps/web/scripts/migrate-microcms.ts` — 移行スクリプト本体
  - **読み取り**: 旧サービスの Content API を全件ページネーション取得（`announcements / interviews / members / reports / achievements`、`server-fn/` と一致）
  - **書き込み**: 新サービスへ `PUT /api/v1/{endpoint}/{id}` で**コンテンツ ID を引き継いで**投入（`/report/$id` などの詳細 URL を維持／冪等で再実行可）
  - **画像**: `NEW_MICROCMS_MANAGEMENT_API_KEY` があれば Management API で再アップロード（本文 HTML 内の `<img>` も対象）。無ければ旧 CDN の URL を参照（表示は維持）
  - フラグ: `--dry-run` / `--endpoints=a,b` / `--limit=N` / `--skip-media`
- `apps/web/scripts/MIGRATION.md` — スキーマ移植〜接続先切替までの実行手順
- `apps/web/.env.migrate.example` — 移行用 env テンプレート（`.gitignore` を調整して example のみ追跡）
- `apps/web/package.json` — `migrate:microcms` スクリプト追加

## 注意点

- **公開日 `publishedAt` は書き込み API で指定不可**（microCMS のシステム項目）。移行先では「移行実行日時」になるため、`publishedAt` を表示・並び替えに使う `reports / interviews / announcements` は**古い順に書き込んで相対的な並び順だけ維持**する。`achievements` は独自の `achievedAt` を使うため影響なし。
- **下書き（未公開）コンテンツは移行対象外**（Content API は公開済みのみ返すため）。
