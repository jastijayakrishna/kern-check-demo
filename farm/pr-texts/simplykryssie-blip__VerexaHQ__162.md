# Design refresh Phase 1: warm canvas + brand gradient on active nav

## Summary

First phase of a broader visual refresh (design concept approved by the user) aimed at making the product feel more like Verexa's own identity and less like generic enterprise software.

Verexa's actual logo (`public/brand/vmark.png`) is a vivid blue-to-lime gradient -- nothing in the live product used any of it; every surface ran on one flat, muted azure against a cool blue-gray neutral.

- `surfaceMuted` (the page background used everywhere) shifts from a blue-biased neutral to a warm, sage-biased one -- ties to the green half of the mark the same way the previous value tied to its blue half. Added a `brandLime` token (tempered down from the mark's own acid green for legibility as a UI color).
- The sidebar's active-nav-item pill is now the real two-color brand gradient instead of a flat tint, for any workspace that hasn't customized their own sidebar color via Brand Center.
- **No regression for a firm that has customized their branding**: when a workspace has set its own `secondaryColor`, the active-nav pill stays exactly the flat tint of their own color it's always been -- the gradient never blends an unrelated custom color with lime. This branches in `Sidebar.tsx` on the same `secondaryColor` prop that already drove the flat-tint override, so existing white-labeled workspaces are byte-for-byte unaffected.

## Verification

- `tsc --noEmit`, `eslint`, and `npm run build` all pass clean.
