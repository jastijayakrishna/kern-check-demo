# Add simple Next.js frontend for chat example with streaming support

Adds a minimal Next.js frontend to the chat example that allows submitting messages and streaming responses using the vellum-ai SDK. The frontend uses only Next.js and React with no additional UI libraries, providing a simple yet professional chat interface.

The frontend is integrated directly into the existing `examples/chat/` directory with a unified package.json that supports both the CLI scripts (`npm run api`, `npm run fetch`) and the web frontend (`npm run dev`).

https://www.loom.com/share/1038fd080ebb4f9cb33a2ea2202b3fa2

The goal is to have this example as a reference for both agentic and human developers
