# Revamp app to X.com style — mobile-first, whole-app, verified in-browser

A whole-app re-skin to an **X.com** look, **verified in a real browser** (mobile + desktop) screen by screen. The Supabase backend is untouched. App name stays **G-BAU-G**.

## Why this is different from the last attempt
The previous PR was merged then reverted (#13) because it only restyled the **auth-gated feed** — a guest still saw the old cream/gold dashboard on every public screen, and I never ran the app to see it. This pass fixes the **visible, verifiable** surfaces first and was checked with screenshots at each step (Home, Login, Membership, Directory, Products, Market, footer, mobile + desktop).

## Design system — repaints every screen at once
- `index.css` tokens → X palette: white surface, `#0F1419` ink, **X-blue `#1D9BF0`** primary; "lights out" black for dark. Legacy `--gold*` tokens **remapped to blue**, so every old gold accent reads blue app-wide with no per-file edits.
- `Card` flattened to **border-only** (removes the drop-shadow "dashboard" look — the biggest tell).
- Buttons flattened to X pills; social tokens `--like` / `--repost` / `--verified` added.

## Screens (all verified in-browser)
- **Home** — bold monochrome hero, blue CTAs, flat quick-action tiles.
- **Header / bottom tabs** — X pill search; icon-forward tab bar with the **user avatar on the Account tab**.
- **Footer** — was a **full-bleed blue slab** → clean bordered footer.
- **Login / Membership / Directory / Products** — clean via the token system; ProductPage hero de-slabbed; fixed an `About` **blue-on-blue** regression (blue text on blue bg).

## Feed — real X mechanics
- Tap an **image** → full-screen **lightbox** (keyboard / swipe / counter).
- Tap a **handle/avatar** → storefront profile (resolved via `companies_public.owner_id → slug`) with a **verified check** and a **Follow / Following** button.
- Tap a **post** → `/market/:postId` **detail page** with inline replies.
- X action bar (reply · repost · like · views · bookmark · share); edge-to-edge 600px feed column with hairline dividers; round X-blue compose FAB.

## ⚠️ Honest caveat
Follow / repost / bookmark are **client-side** (localStorage, behind a swappable interface) because there is no `follows` table and the brief said keep the backend as-is. The market feed stays **gated to verified members** by existing product rules — it's restyled, not un-gated.

## Backend
Untouched. Two **read-only** helpers added against existing objects: `getPost(id)` and `listCompaniesByOwners(ids)` (public view only — no contact columns).
