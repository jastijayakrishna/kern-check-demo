# feat(web): Keyring-first homepage + zero-JS agent contract

Repositions the marketing site around Keyring (homepage spec) and makes every marketing route readable via `curl` with zero JS. Also folds in a small request: the BasedAgents name/logo on the console auth screens is now a clickable link back to the homepage.

## Rendering split (static homepage)
The site was a React SPA; the spec requires curl-readable, no-JS pages.
- **`index.html` is now a static Keyring-first homepage** — full copy in server-delivered HTML: hero ("Stop pasting master keys into .env"), the hotel-key-card story, a 3-tile control strip, the under-the-hood registry story, an "Are you an agent?" section, the provider grid, condensed pricing, closing.
