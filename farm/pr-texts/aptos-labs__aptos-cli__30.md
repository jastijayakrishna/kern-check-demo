# Pre-packaged cli version support

Add support for installing and updating a specific Aptos CLI version via the `APTOS_CLI_VERSION` environment variable.

This allows users to pin to a particular CLI version, test against specific versions, or ensure reproducible builds in CI/CD pipelines by bypassing package managers and downloading directly from GitHub releases.

Closes https://github.com/aptos-labs/aptos-cli/issues/8
