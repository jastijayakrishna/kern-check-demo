# Revamp feed UI/UX to X.com style with polished interactions

Re-skins the app to an **X.com** look and closes the biggest feed interaction gaps, keeping the Supabase backend untouched. App name stays **G-BAU-G**.

This is a strong starting point that fixes the reported gaps — not a finished product. A full forward plan lives in `docs/x-style-revamp.md`.

## Why
The current UI was a good start but far from an X-style, mobile-first, polished product. Specific gaps called out: tapping an image didn't open it, handles didn't open profiles, and there was no way to follow an account or open a post.

## What changed

**Design system → X palette (repaints the whole app)**
- Retheme `index.css` tokens *in place* (names kept, values swapped): white + near-black + **X-blue `#1D9BF0`** for light, "lights out" pure black for dark. All ~28 pages inherit it with no per-page edits.
- New social-action tokens `--like` / `--repost` / `--verified` (registered in Tailwind); buttons flattened to X-style pills.

**Feed is now a real X feed**
- **Tap an image → full-screen lightbox** (`ui/lightbox.tsx`): backdrop close, prev/next, keyboard arrows, mobile swipe, `n / total` counter, scroll lock — with an X media grid (1 / 2 / 3 / 4+ with `+N` overflow).
- **Tap a handle/avatar → profile**: authors resolve to their storefront via `companies_public.owner_id → slug`; verified businesses get a blue check.
- **Tap a post → detail page** (`/market/:postId`): whole-card click (interactive children excluded), large post + inline reply composer and replies.
- **X action bar**: reply · repost · like (heart) · views · bookmark · share, with X hover tints. Like uses the real backend; repost/bookmark are local toggles; share uses Web Share / clipboard.
- Feed re-laid out as an edge-to-edge 600px column with hairline dividers.

**Follow**
- X-style Follow / Following (hover → Unfollow) on every author, backed by a small **client-side** store with a deliberately swappable interface. See the caveat below.

**Mobile shell**
- X-style bottom tab bar (avatar on the Account tab), round X-blue compose FAB, cleaner pill search.

## Backend
Untouched. Adds two **read-only** repository helpers against existing objects: `getPost(id)` and `listCompaniesByOwners(ids)` (public view only — no contact columns).

## ⚠️ One honest caveat — follow is client-side
The brief says keep the backend as-is, and there's no `follows` table, so follow/repost/bookmark state lives in `localStorage` behind a swappable interface. It's real and instant per device but doesn't persist server-side yet. `docs/x-style-revamp.md` includes the exact `follows` table + RLS to make it first-class, after which only the four function bodies in `src/lib/follow.ts` change (no caller changes).
