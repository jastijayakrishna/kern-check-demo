# Prune dead feed suggestions + make the checker Reddit-friendly

Acting on a real `npm run feeds:check` run against the catalog. Two commits:

## 1. Make the checker Reddit-friendly (`scripts/checkFeeds.mjs`)

The checker fired all same-host feeds concurrently, so the six `reddit.com` feeds hit Reddit in parallel and tripped its rate limiter — every one reported a spurious **429** despite being healthy. (The production poller never sees this: it uses a descriptive UA, honors `Retry-After`, and fetches each feed on its own interval — one at a time.)

- **Per-host serialization:** at most one in-flight request per hostname; different hosts still run concurrently up to the pool size. Reddit's feeds now go one-at-a-time and pass.
- **Retry once on 429** after honoring `Retry-After` (numeric seconds, capped so a run never stalls). Extracted `retryDelayMs` as a unit-tested pure helper.

## 2. Remove dead suggestions (`src/lib/popularFeeds.ts`)

A curated suggestion bypasses discovery and subscribes to the URL directly, so a dead one creates a subscription that never refreshes. Removed 18:

- **Discontinued / shut down:** Reuters (no public RSS since ~2020), AnandTech (closed 2024).
- **401/403 bot-blocked:** AP News, Politico, The Australian, Financial Times, Money Saving Expert.
- **404 / moved:** Forbes, The Boston Globe, The Athletic, Vulture, Anthropic News.
- **Served HTML/JSON, not a feed:** USA Today, ESPN, Gates Notes, and the News Corp AU mastheads on `/news/breaking-news/rss` (Herald Sun, The Daily Telegraph, The Advertiser — that path returns JSON).

**Kept** The Courier-Mail and PerthNow (other News Corp AU papers, different paths, not in the failure set) — to confirm on the next checker run. **Not removed** (transient, not dead): CBC (timeout), Slate (conn reset), and the Reddit feeds (the 429 was the checker artifact fixed above).

### On "how to poll Reddit"
The poller is already correct — `User-Agent: Readmo/1.0 (+https://readmo.app)` (Reddit 429s generic/browser-spoof UAs), `429`/`Retry-After` soft-backoff with reschedule, and spaced per-feed fetches. No poller change needed; the only Reddit issue was the checker's concurrent burst, now fixed.
