# Fix two things the first run on real hardware showed

Follow-up to #29, from reading a real `gethome-hubctl update` on a Zero 2 W with a factory-fresh SONOFF ZBDongle-E. The mechanism worked end to end — `zigbee.problem` reached `GET /hub`, the installer named the firmware failure with the right link, `@@CAPABILITIES@@` correctly dropped Zigbee. These are the two things that were wrong in the output.

## The install's last line undercut its own warning

The run ended like this:

```
==> WARNING: The Zigbee coordinator answered, but its firmware is too old …
@@CAPABILITIES:Wi-Fi and MQTT@@
==> This hub can talk to: Wi-Fi and MQTT.
==> This board has memory for one radio at a time, and the Zigbee coordinator
    you plugged in has it, so Matter is off. You can switch to Matter …
```

Every sentence is true and the last one reads as *all set* — on a hub that can talk to **no radio at all**. Matter is off because Zigbee has the board; Zigbee doesn't work because of the firmware. Nothing said so.

The branch keyed on `ZIGBEE_CONFIGURED` (the board went to the coordinator) and the gap between that and `ZIGBEE_READY` (Zigbee2MQTT actually reached it) is exactly a small board running neither radio. The installer keeps those two facts apart everywhere else — this was the one place it collapsed them. Now split, with the new case naming the state and offering Matter as the meanwhile:

> This board has memory for one radio at a time and the coordinator has it, so Matter is off — and until the coordinator is talking, this hub is running neither radio. Sort out the warning above and Zigbee starts on its own. If you would rather use Matter meanwhile, switch this board in the GetHome app; the coordinator stays configured and Zigbee devices come back when you switch back.

## `detail` carried Zigbee2MQTT's indentation into the app

Straight off the hub:

```json
"detail": "[2026-08-09 17:34:24] error: \tz2m: Error: Adapter EZSP protocol version (8) is not supported by Host [13-19]."
```

Z2M indents its own lines. The field is rendered as **one line** in an app, where an embedded tab is a hole in the middle of a sentence rather than a column. Whitespace runs are collapsed now, and the fallback paths go through the same tidy so they can't reintroduce it.
