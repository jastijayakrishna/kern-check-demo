# Fix mobile Site Planner: unreachable section rail, tab-row clipping, zoom control over scale bar

## Summary

Owner report (Michael, iPhone Safari, ~390pt wide, real signed-in site): on a phone the Site Planner is largely unusable. Three fixes, all reproduced and verified with real device-emulated Playwright (iPhone 13, 390×844, real touch) against a real captured production plan fixture (`ui-audit/fixtures/bain-concept-original.json`), proven red on pre-fix code and green after.

- **B917072** — the six-section rail (Land/Analysis/Yield/Properties/References/Standards) rendered inline at a fixed width on every viewport, permanently costing screen real estate with nothing open. It now overlays the canvas at phone width — off-screen when idle, summoned by a new "☰ Sections" button that mirrors the existing "✎ Tools" one, and stays on-screen while its panel is open. Diagnosed first (per the brief's requirement): the "✎ Tools" draw-tool palette already worked correctly on real touch taps — the actual defect was the separate, always-visible section rail.
- **B917073** — the workspace tab row (Site/Schedule/Review/Library/Notes/Markup) is a sideways-scrolling strip with no visible scrollbar, and nothing kept the *active* tab in view across a module switch that didn't come from tapping an already-visible tab (a deep link, a restored session). Fixed with an effect that scrolls the active tab into view on every module change, plus a CSS edge-fade mask on both scrollable header rows so hidden content is signaled rather than silently clipped.
- **B917074** — the two "unstyled white rectangles" over the map turned out to be one real, correctly-styled control (the zoom-control column) at the wrong vertical offset: its `bottom: 100` never picked up the same `FAB_RESERVE_PX` reserve the furniture row gets on narrow width, so it collided with the scale bar and painted over its "…0 FEET" readout. Fixed by applying the same reserve.

Full detail, root-cause tracing, and verification notes for each are in `BACKLOG-DONE.md` (B917072/B917073/B917074).
